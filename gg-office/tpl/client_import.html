Import clients from Excel

  1. Open your client list in Excel. The first row must have column headings. Only Name is required; GG Office also reads: {{range $i, $c := .V.Cols}}{{if $i}}, {{end}}{{$c}}{{end}}.
  2. In Excel choose File → Save As → CSV UTF-8 (Comma delimited).
  3. Choose that file below and click Import. Clients already in the list (same PAN, or same name when there is no PAN) are skipped, so importing twice is safe.
